I build machine-learning methods that make expensive scientific simulators actually usable — teaching agent-based models of biological systems to match real experimental data with as few simulator runs as possible.

### 🔬 Currently
- PhD at the **University at Buffalo**, advised by Dr. Ashlee N. Ford Versypt
- Building a constrained **Bayesian-optimization** framework — Gaussian-process surrogates + a feasibility-aware acquisition function — to calibrate [CompuCell3D](https://compucell3d.org/) models of collective **cancer-cell invasion**
- Thinking about scientific ML, **uncertainty quantification**, and simulation-based inference
